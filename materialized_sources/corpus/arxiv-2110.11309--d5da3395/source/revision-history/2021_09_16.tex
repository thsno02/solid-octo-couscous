\paragraph{Model Agnostic Meta-Learning (MAML)}
The model-agnostic meta-learning algorithm \citep{finn2017maml} for few-shot learning searches for an initialization of the model parameters such that a single step (or a small number of steps) of gradient descent can find parameters that achieve low loss on a new task. The `single step' version of MAML solves the following optimization problem:
\begin{align}
    \theta^*_\text{MAML} = \arg\min_\theta \mathbb{E}_{\mathcal{D}_s,\mathcal{D}_q}\mathcal{L}_\text{outer}(\theta - \eta \nabla_\theta \mathcal{L}_\text{inner}(\theta, \mathcal{D}_s), \mathcal{D}_q)
\end{align}
where $\mathcal{D}_s$ is a set of `support' examples used to update $\theta$, $\mathcal{D}_q$ is a set of `query' examples used to evaluate whether adaptation was successful, and $\eta$ is the learning rate used for parameter adaptation. Often $\mathcal{L}_\text{outer} = \mathcal{L}_\text{inner}$, but this need not be the case.

\paragraph{Editable Neural Networks (ENN)}
\label{sec:enn-prelims}
Editable neural networks \citep{Sinitsin2020Editable} search for a set of model parameters that both provide good performance for a `base task' (e.g. image classification or machine translation) and enable rapid editing by gradient descent to update the model's predictions for a set of `edit examples' without changing the model's behavior for unrelated inputs. ENN optimizes the following MAML-based objective:
\begin{align}
    \mathcal{L}_\text{ENN}(\theta, \mathcal{D}_\text{base}, \mathcal{D}_\text{edit}, \mathcal{D}_\text{loc}) = \ell_\text{base}(\mathcal{D}_\text{base}, \theta) + c_\text{edit}\cdot\ell_\text{edit}(\mathcal{D}_\text{edit}, \theta^\prime) + c_\text{loc}\cdot\ell_\text{loc}(\mathcal{D}_\text{loc}, \theta, \theta^\prime).\label{eq:enn-loss}
\end{align}
The first term of Equation~\ref{eq:enn-loss} is the base task loss; for a generative language model, we have $\ell_\text{base}(\mathcal{D}_\text{base}, \theta) = -\log p_{\theta}(\mathcal{D}_\text{base})$ where $\mathcal{D}_\text{base}$ is a batch of training sequences. $\ell_\text{base}$ is the edit \textit{reliability} loss, encouraging the model to significantly change its output for the edit examples in $\mathcal{D}_\text{edit}$. Finally, $\ell_\text{loc}$ is the edit \textit{locality} loss, which penalizes the edited model $\theta'$ for deviating from the predictions of the pre-edit model $\theta$ on $\mathcal{D}_\text{loc}$, data unrelated to $\mathcal{D}_\text{edit}$ and sampled from the same distribution as $\mathcal{D}_\text{base}$.

The editing procedure and corresponding losses are defined as follows:
\begin{align}
    \label{eq:enn-edit}\theta^\prime = \text{Edit}(\mathcal{D}_\text{edit}, \theta) &= \theta + \eta \nabla_\theta \log p_\theta(\mathcal{D}_\text{edit}) \\
    \label{eq:enn-edit-outer}\ell_\text{edit}(\mathcal{D}_\text{edit}, \theta') &= -\log p_{\theta^\prime}(\mathcal{D}_\text{edit}) \\
    \label{eq:enn-loc}\ell_\text{loc}(\mathcal{D}_\text{loc}, \theta, \theta^\prime) &= \frac{1}{N}\sum_i^N D_{KL}(p_\theta(\cdot \mid x_\text{loc}^i)\,\|\, p_{\theta^\prime}(\cdot \mid x_\text{loc}^i)).
\end{align}
where $\mathcal{D}_\text{loc} = \{(x_\text{loc}^i, y_\text{loc}^i)\}_{i=1}^N$ is a batch of $N$ training examples, $\ell_\text{edit}$ ensures that edited parameters actually increase the likelihood of the edit example(s), and $\ell_\text{loc}$ regularizes edits to affect only the edit example(s). See \citet{Sinitsin2020Editable} for a more detailed explanation of ENN training and alternative objectives for $\ell_\text{edit}$ and $\ell_\text{loc}$. Comparing ENN with the notation used for MAML, we have negative log likelihood on $\mathcal{D}_\text{edit}$ for $\mathcal{L}_\text{inner}$ (Equation~\ref{eq:enn-edit}) and $\ell_\text{edit} + \ell_\text{loc}$ for $\mathcal{L}_\text{outer}$ (Equations~\ref{eq:enn-edit-outer} and~\ref{eq:enn-loc}). 

\paragraph{\textsc{KnowledgeEditor} (KE)}
\cite{Cao2021EditingFK} propose \textsc{KnowledgeEditor}, a hypernetwork-based approach for editing the knowledge in language models. KE trains an \textit{editor network} (e.g. an RNN) that conditions explicitly on the edit example and label and outputs a mask $m_i$, offset $b_i$, and a scalar scaling factor $\alpha$ to the gradient $\nabla_{W_i}$ for several of the weight matrices in a transformer model, where $m_i,b_i,\nabla_{W_i} \in \mathbb{R}^{d \times d}$ for a $d \times d$ weight matrix. The update to the model is $\theta' = \theta - \alpha (m_i \circ \nabla_{W_i}) + b_i$. To maintain tractability in light of the large weight matrices in state of the art transformer models, the mask and offset output by KE are rank-1.

\section{Experiments}
Our experiments are intended to answer several questions about algorithms for editing transformers. First, how does each algorithm trade off edit success with model degradation induced by editable training and the edits themselves? Second, to what extent is explicit supervision over how edits should generalize needed during training? Third, does \name~scale to very large (billion+ parameter) transformer models? Finally, are the design components such as identity initialization and input normalization actually necessary?

Finally, we conduct ablation studies to validate the key components of \name, including identity initialization, input normalization, and MLP weight rank. For the initialization ablation, we replace identity initialization with standard Xavier (or Glorot) initialization. We used a single fixed $c_\text{edit}$ for all experiments. Table~\ref{tab:ablations} shows the results. While reducing the rank of the \name~weight matrices yields a gentle degradation in overall editability, removing \textit{either} input normalization or the identity initialization results in essentially complete failure of learning. To understand why input normalization is so important, we plot the distribution of the average per-dimension absolute value of the two inputs to \name, $x$ and $\delta$ for all three editing settings in Figure~\ref{fig:x-delta}. The average activation tends to be orders of magnitude larger than the average $\delta$. We conclude that normalization likely balances the contribution of these two inputs to the gradient update to the \name~parameters, which would otherwise be a very poorly-conditioned problem. Further, the magnitude of activations varies significantly across tasks. Normalization makes the scale of \name~parameter updates similar across tasks, enabling the usage of the \textbf{same hyperparameters} for all experiments.

\section{Limitations}
\begin{enumerate}
    \item Can't do sequences of edits (future work)
    \item Didn't try batched edits (but this should work)
    \item Required labeled input rephrasings (future work)
    \item Editing single facts is just one (rather limited) type of edit
\end{enumerate}
\section{Discussion}
In this work, we presented an efficient, first-order algorithm for neural network editing. We showed that it can make model edits that generalize well to semantically-equivalent inputs. Future work should fix more of the problems preventing these algs from being practical.
